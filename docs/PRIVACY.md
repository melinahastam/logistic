# Public Portfolio Boundaries

This repository is intentionally documentation-only.

## Included

- High-level product description
- Architecture and data-flow diagrams
- Sanitized API inventory
- Approved screenshots
- Engineering responsibilities and technology choices

## Excluded

- Production source code and Git history
- `.env` files, credentials, tokens, cookies, and session data
- Internal IP addresses, domains, ports, and deployment commands
- Database names, connection strings, table details, and customer payloads
- Customer, employee, driver, visitor, and account identifiers
- Real order numbers, phone numbers, addresses, coordinates, and exports
- Logs, backups, compiled bytecode, archives, and temporary files

## Screenshot policy

Before publication, verify every screenshot at 100% zoom. Blur or replace:

- Names and usernames
- Order/customer/route identifiers
- Phone numbers and addresses
- Exact operational dates when sensitive
- Browser address bars and local URLs
- Notifications containing internal state
- Any map point that identifies a private customer location

Public map labels and provider attribution should remain visible when required by the map provider's terms.
